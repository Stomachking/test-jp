Chart language
Bars: thin, rounded data end
Markers: ink dot, paper ring
Guides: hairline, dashed for averages
Text never wears the data colour. One hue for magnitude, ink for the point that matters.
Motion principles
  • Reveal on scroll: 400 ms fade and 8 px rise, once
  • Bars grow from the baseline, 900 ms ease-out
  • Hero numbers count up over 1.2 s
  • Lines draw left to right, 1.4 s
  • Reduced-motion: everything lands instantly
What changes from the current build
  • Copy per block cut to a lede, “read more” holds the rest
  • One hero graphic opens every section
  • Charts move to full width above the copy
  • Poll becomes a one-line chip row, not a card
